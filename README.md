## Current foundation

The app currently provides Home / Challenges / Settings navigation, a ledger-backed financial model, locally persisted saving goals, multi-currency balances and explicit SYP↔USD conversions.

Future implementation is tracked as ordered GitHub Issues in `docs/ROADMAP.md`.
