# Mo Save

Single-user, offline-first Flutter app for personal finance tracking and gamified saving goals.

## Project docs

- [Product scope](docs/PRODUCT.md)
- [Client-ready roadmap](docs/ROADMAP.md)

## Current foundation

The app currently provides Home / Challenges / Settings navigation and an interactive locally persisted saving-challenge system with USD, SYP and SYP (N) support.

Future implementation is tracked as ordered GitHub Issues in `docs/ROADMAP.md`.
